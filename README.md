# Pavage

Métré et devis de chantiers de pavage et de carrelage : plan façon SketchUp, matériaux et calepinage, couches, bordures, murs carrelés, planning, variantes, suivi et plusieurs projets archivables.

- Appli : `app.html` (fichier unique, fonctionne hors ligne)
- APK : https://github.com/kaniel-outiss/pavage/releases/latest/download/pavage.apk
- Chaque push sur `main` recompile l'APK (GitHub Actions) avec une clé de signature fixe : les mises à jour s'installent par-dessus l'ancienne version.
